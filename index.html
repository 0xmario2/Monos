FAQ
Frequently asked questions
GENERAL
What is Monos?+
Monos is a mint terminal for Base. You can generate wallets, bulk check whitelist, and mint faster than manual. No install, works in browser. Same flow as umi.bot but optimized for Base 8453.
How long has Monos been around?+
Built in 2025, public since 2026. Over 80k mints handled via internal tools before launch.
Is Monos hard to use for beginners?+
No. Click Launch App, connect wallet, generate wallets, and mint. No code.
USAGE & FEATURES
Is it safe to use Monos?+
Yes. 2-layer encryption, keys stored locally, never sent to server. Non-custodial.
Can Monos detect whitelisted wallets?+
Yes. Bulk whitelist checking included in both On-demand and Pro.
How fast is Monos?+
Built-in RPC + proxy, no custom RPC needed. Fast mint anywhere.
Do failed mints cost gas?+
Failed tx still costs gas on Base. We simulate to reduce fails.
